# Portal Gun mod

A Minecraft mod that provides portal gun using [Immersive Portals](https://github.com/iPortalTeam/ImmersivePortalsMod) functionality.

It's a fork of [MeowMC's Portal Gun mod](https://github.com/MeowMC/PortalGun).

### Minecraft 26.3

This branch ports the mod to Minecraft 26.3, on top of Kojimo's 1.21.1 port ([iPortalTeam/PortalGun#26](https://github.com/iPortalTeam/PortalGun/pull/26)).
Immersive Portals itself stops at 1.21.1, so it needs [Immersively Vibed Portals](https://github.com/nyannoying1337/ImmersivelyVibedPortals) 6.1.0-beta.12,
a community port that is still in beta, plus GeckoLib 5.5.7, Cloth Config and Fabric API. Build with `./gradlew build` (Java 25).
